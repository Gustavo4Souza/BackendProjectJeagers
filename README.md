# BackendProjectJeagers

// EH brewing - Gerência de Dados
A EH brewing possui diversos fermentadores que trabalham de maneira independente entre si, existem controladores de temperatura individuais para cada fermentador, mas a configuração e acompanhamento ocorre apenas localmente. O desafio consiste em estruturar uma solução capaz de aquisitar dados de temperatura e densidade do mosto nos fermentadores em tempo real, com as informações sendo disponibilizadas via web, seguindo padrões de qualidade no desenvolvimento da solução.
